# Brickers24 Partners — maqueta

Maqueta de la página pública del Brickers Partner Network: presentación del programa, cómo funciona, vista de ejemplo del panel de partners, proyectos de muestra y formulario de registro.

- Archivo único: `index.html` (HTML, CSS y JS sin dependencias, salvo Google Fonts).
- El formulario es de demostración y todavía no guarda datos.
- Para publicarlo: conectar este repositorio a Vercel o activar GitHub Pages desde la rama `main`.
